# Voice Skill Output Templates

These templates are the standard emission shape for clinician-specific voice
skills generated by `voice-extractor`.

Use them to keep generated skills consistent across clinicians.

## Files

- `SKILL.template.md`
- `style-guide.template.md`
- `style-rules.template.yaml`
- `evidence.template.md`
- `examples.template.md`
- `audit-checklist.template.md`

## Usage Rule

When `voice-extractor` generates a new voice skill, it should:

1. create the target skill directory under `.opencode/skills/<voice-name>/`
2. copy the template structure conceptually
3. replace placeholders with corpus-derived content
4. preserve all safety guardrails unless the new corpus justifies tighter ones

## Placeholder Convention

Use angle-bracket placeholders such as:

- `<VOICE_NAME>`
- `<CLINICIAN_NAME>`
- `<SOURCE_DIRECTORY>`
- `<REPORT_COUNT>`

Placeholders should be fully resolved in generated output.
