# <CLINICIAN_NAME> Voice Audit Checklist

Use this checklist after applying `<VOICE_NAME>` to a draft.

## 1. Fact Preservation

- [ ] No factual content was added.
- [ ] No factual content was removed.
- [ ] Chronology and source meaning remain intact.

## 2. Attribution Preservation

- [ ] Collateral information still sounds collateral.
- [ ] Self-report still sounds like self-report.
- [ ] Record-based information still sounds record-based.
- [ ] Attribution was not removed for the sake of smoother prose.

## 3. Uncertainty Preservation

- [ ] Caveats were preserved.
- [ ] Ambiguity was not falsely resolved.
- [ ] Certainty was not strengthened beyond the original draft.

## 4. Diagnosis Leakage Check

- [ ] No new diagnosis language was introduced.
- [ ] Symptom descriptions were not upgraded into conclusions.
- [ ] Style transfer did not import diagnostic framing from exemplar reports.

## 5. Section Integrity Check

- [ ] Age branch remains correct.
- [ ] Section ontology remains correct.
- [ ] Section purpose remains unchanged.
- [ ] Any section overlay used was supported by the generated artifacts.

## 6. Overfitting Check

- [ ] The rewrite does not rely too heavily on one repeated phrase.
- [ ] The rewrite reflects corpus style, not one report's quirks.
- [ ] Boilerplate wording was not mistaken for clinician-specific voice.

## 7. Tone and Cadence Match

- [ ] Tone matches the extracted clinician voice.
- [ ] Sentence cadence reflects the corpus profile.
- [ ] Paragraph rhythm reflects the corpus profile.
- [ ] The result sounds polished without becoming more interpretive.

## 8. Final Safety Check

- [ ] The rewrite remains style-only.
- [ ] If content change would be required, that need has been surfaced explicitly.
